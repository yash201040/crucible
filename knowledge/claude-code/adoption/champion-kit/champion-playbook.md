# What it is

A playbook for engineers who already use Claude Code and want teammates to adopt it. Three behaviors: share what you discover, be the person people ask, grow the circle.

# How to use it

- Time budget per week: posting wins about 15 minutes; answering questions about 20; weekly show-and-tell thread about 5; optional pairing 0 to 30.
- Share in an engineering/`#claude-code` channel, PR descriptions, standups, team wiki; best format is a screenshot plus one or two sentences.
- Answer with the actual prompt used, and point at the feature (plan mode via Shift+Tab) rather than docs.
- Thirty-day plan: week 1 seed channel; week 2 start weekly thread and share a skill or CLAUDE.md snippet; week 3 pair and pin an FAQ; week 4 hand off to a second champion.
- Run `/team-onboarding` in a well-used project: Claude scans recent sessions, commands and MCP servers and produces a guide a new teammate can paste as a first message.
