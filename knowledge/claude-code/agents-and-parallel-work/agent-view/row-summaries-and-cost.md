# What it is

The one-line summary in each row is generated by a Haiku-class model so the row says what the session is doing, needs or produced. While a session is working, the row text updates at most once every 15 seconds from its recent output with no model request; a model writes a fresh summary when each turn ends and rewrites it every few minutes during long turns. A blocked row shows the question. When the list is grouped by directory, the summary starts with a coloured state word such as `Needs input · double jump or wall climb?`.

# Limits and defaults

Cost: the end-of-turn summary and each mid-turn rewrite are one short request through your normal provider, billed and covered by the same data usage terms as the session. On a third-party provider or gateway they use `ANTHROPIC_DEFAULT_HAIKU_MODEL`; if unset, the provider's background-task model. Peek panel shows text the terminal edge clips.
