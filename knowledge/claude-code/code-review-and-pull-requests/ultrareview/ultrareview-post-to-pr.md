# What it is

On Claude Code v2.1.227 or later, a github.com PR review can post its findings as one plain comment (not a review or approval) from the user's own GitHub account, ending with a "Generated by Claude Code" note. `--no-post` is the default; posting is chosen per run. Branch reviews only show findings in the session.

# How to use it

- Interactive: pick "Run and post the findings to the PR as me" in the launch dialog; `/code-review ultra 1234 --post` preselects it but still asks.
- Non-interactive: `claude ultrareview --post` posts without asking (running with the flag is the consent). `claude -p '/code-review ultra'` posts nothing.

The post is made by the Anthropic API (the session ID is sent), through the GitHub account connected to Claude, not from the machine. Outcomes: Posted (link), Already posted (link to PR), Failed (reason; findings stay in the terminal).

# Limits and defaults

- Needs the same claude.ai sign-in; unavailable on third-party providers or with `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` set.
- Interactive posting starts when findings arrive, so keep the session open; if it ends first, nothing is posted, even if resumed later.
- With both flags, `--no-post` wins. On non-github.com targets the flag is ignored with a notice.
