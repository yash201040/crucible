# What it is

A plugin built locally exists only on your machine. Routes to share: give people the directory or `.zip` (nothing published); list it in your own marketplace so teammates add it once, install by name and receive updates; or submit to Anthropic's directory (after review, people add it on claude.ai and Cowork and it reaches Claude Code through their account). The same folder installs on claude.ai and Cowork with a different component subset. Details in [publish page concepts](../plugins-publish/choose-how-to-distribute.md).
