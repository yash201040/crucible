# interface/voice-dictation

* [Voice dictation setup and requirements](enable-voice-dictation.md) - The /voice command and voice settings enable hold or tap speech-to-text for the prompt; needs a claude.ai account and a local microphone.
* [Hold, tap, cancel and rebind dictation](hold-tap-and-rebind.md) - Hold mode records while a key is held; tap mode toggles recording and auto-sends; Esc or Ctrl+C cancels; voice:pushToTalk rebinds the key.
* [Voice dictation error messages](voice-troubleshooting.md) - Common /voice error messages and their fixes: account, policy, microphone, SoX, WSL, repeated failures, connection and speech detection.
