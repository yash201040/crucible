# What it is

This page only points to the Managed MCP configuration page, which covers deploying a fixed server set with `managed-mcp.json`, giving every user servers with `managedMcpServers`, restricting servers with `allowedMcpServers` and `deniedMcpServers`, and what users see when a server is blocked. See [installation scopes](./installation-scopes-and-precedence.md) and [connector controls](./connector-delivery-and-org-controls.md) for the behavior this page describes.
