# settings/settings-reference

* [Advisor model and thinking settings](p1-advisor-and-thinking.md) - advisorModel, alwaysThinkingEnabled, showThinkingSummaries: choose the advisor model and control extended thinking and its display.
* [Auto memory and CLAUDE.md settings](p1-auto-memory-and-claudemd.md) - autoMemoryEnabled, autoMemoryDirectory, claudeMd and claudeMdExcludes control memory storage and which CLAUDE.md files load.
* [Auto mode settings](p1-auto-mode-settings.md) - autoMode rules and classifyAllShell, disableAutoMode, useAutoModeDuringPlan, skipAutoPermissionPrompt and skipDangerousModePermissionPrompt. **[high]**
* [Block reads and writes outside working directories](p1-block-outside-working-dirs.md) - permissions.blockReadsOutsideWorkingDirectories and blockWritesOutsideWorkingDirectories make file tools refuse outside paths in every mode. **[high]**
* [File checkpointing and Bash output limit](p1-checkpointing-and-bash-output.md) - fileCheckpointingEnabled (rewind snapshots, ignored in -p and SDK) and bashOutputMaxChars (inline output cap, 4000 to 128000). **[high]**
* [Compaction settings](p1-compaction-settings.md) - autoCompactEnabled, autoCompactWindow and idleCompaction control automatic and idle context compaction, with env and flag overrides. **[high]**
* [permissions.denyInsteadOfPrompting](p1-deny-instead-of-prompting.md) - Makes a session with no human present deny calls that would prompt, so the turn continues; also removes question and plan tools and cancels elicitations. **[high]**
* [Effort level settings](p1-effort-level-settings.md) - effortLevel, maxEffortLevel and modelSettings set, cap and save per-model reasoning effort (low to max), with precedence rules. **[high]**
* [env setting and ignored variables](p1-env-setting.md) - The env key sets environment variables for every session and subprocess; lists which variables project and local settings may not set. **[high]**
* [Fast mode and ultracode settings](p1-fast-mode-and-ultracode.md) - fastMode, fastModePerSessionOptIn and ultracode: speed-for-cost fast mode and automatic workflow planning. **[high]**
* [Index: agents, sessions and worktrees keys](p1-index-agents-sessions-worktrees.md) - Settings keys for starting as a subagent, agent view, cross-session messaging, teammate display, process wrapper and worktree creation (index rows only). **[high]**
* [Index: authentication, managed and update keys](p1-index-auth-enterprise-updates.md) - Settings keys for credential helpers, login restriction, provider allowlists, managed-settings behavior, policy helper and version pinning (index rows only).
* [Index: ~/.claude.json global config keys](p1-index-global-config-keys.md) - Keys kept in ~/.claude.json rather than settings files, including IDE, copy, agent view and removed keys (index rows only).
* [Index: hooks and workflow keys](p1-index-hooks-and-workflows.md) - Settings keys for hooks, HTTP hook limits, disabling hooks, and dynamic workflows (index rows only). **[high]**
* [Index: interface and terminal keys](p1-index-interface-terminal.md) - Settings keys for display, input, notifications, status line, themes, voice, accessibility and tools in the desktop browser pane (index rows only).
* [Index: MCP, plugin and skill keys](p1-index-mcp-plugins-skills.md) - Settings keys for MCP server allow and deny lists, managed MCP, claude.ai connectors, plugins, marketplaces, mods and skills (index rows only). **[high]**
* [Index: privacy, git and remote keys](p1-index-privacy-git-remote.md) - Settings keys for transcript retention, surveys, attribution, PR links, Remote Control, desktop sessions, SSH and notifications (index rows only).
* [allowManagedPermissionRulesOnly](p1-managed-permission-rules-only.md) - Managed Boolean that makes managed settings the only source of permission rules and, from v2.1.282, ignores skill allowed-tools from user and repository sources.
* [Model allow and deny lists](p1-model-allowlist-denylist.md) - availableModels, availableModelsMatch, deniedModels and enforceAvailableModels restrict which models can be selected, with prefix or exact matching. **[high]**
* [modelPricing: contracted spend rates](p1-model-pricing-override.md) - Managed key that makes cost figures use organization rates, via a multiplier and per-model overrides, affecting /usage, total_cost_usd and --max-budget-usd. **[high]**
* [Model selection, overrides and fallback](p1-model-selection-and-fallback.md) - model, modelOverrides, modelPicker, fallbackModel, switchModelsOnFlag, language, outputStyle: pick and route models and set response style. **[high]**
* [permissions object and rule arrays](p1-permissions-object-and-rules.md) - permissions.allow, ask, deny, additionalDirectories, defaultMode, disableBypassPermissionsMode and rule syntax, with evaluation order deny then ask then allow. **[high]**
* [Plans directory and skill listing budget](p1-plans-and-skill-listing.md) - plansDirectory, skillListingBudgetFraction, skillListingMaxDescChars, and the removed taskOutputMaxChars.
* [Prompt cache TTL settings](p1-prompt-cache-ttl-settings.md) - promptCacheTtl and subagentPromptCacheTtl choose 5m or 1h prompt cache lifetime for the main conversation versus subagents, workflows and helper requests. **[high]**
* [Sandbox core settings](p1-sandbox-core-settings.md) - sandbox object keys: enabled, failIfUnavailable, autoAllowBashIfSandboxed, excludedCommands, allowUnsandboxedCommands, ripgrep, bwrapPath, socatPath, ignoreViolations. **[high]**
* [Sandbox credential protection and masking](p1-sandbox-credentials-masking.md) - sandbox.credentials files and envVars with deny or mask modes, mask fields (extract, decode jwt, maskClaims, injectHosts), AWS SigV4 pairing and sigv4 handling. **[high]**
* [Sandbox filesystem settings](p1-sandbox-filesystem-settings.md) - sandbox.filesystem lists (allowWrite, denyWrite, denyRead, allowRead), managed lock allowManagedReadPathsOnly, disabled, plus path prefixes and wildcard rules. **[high]**
* [Sandbox network settings](p1-sandbox-network-settings.md) - sandbox.network keys: allowedDomains, deniedDomains, strictAllowlist, allowManagedDomainsOnly, proxy ports, unix sockets, local binding, tlsTerminate. **[high]**
* [Sandbox platform escape-hatch flags](p1-sandbox-platform-hardening-flags.md) - sandbox.enableWeakerNestedSandbox, enableWeakerNetworkIsolation, allowAppleEvents and allowNestedUserNamespaces: security-reducing options for containers, macOS and Linux.
* [Settings reference: scopes and index](p1-settings-index-and-scopes.md) - How the settings reference is organized: each key has a scope (User, Project, Local, Managed, Any file, Global config) listed in a full key index.
* [Agent, cross-session and process settings](p2-agent-and-cross-session-settings.md) - Settings for the default main-thread agent, cross-session messaging, agent view, background process wrapper and teammate display. **[high]**
* [allowManagedHooksOnly](p2-allow-managed-hooks-only.md) - Managed-scope switch that restricts hook execution to managed, SDK and force-enabled plugin hooks. **[high]**
* [allowedProviders](p2-allowed-providers.md) - Managed allowlist of model providers a machine may use, refused at startup, login and next API contact.
* [Artifact tool settings](p2-artifact-tool-settings.md) - enableArtifact turns off the Artifact tool; disableArtifact is its deprecated predecessor.
* [Channel plugin settings](p2-channel-plugin-settings.md) - Managed settings that allow channels and restrict which plugins may push messages into sessions.
* [Credential and header helper settings](p2-credential-helper-settings.md) - Settings that run your own command to supply API keys, AWS or GCP credentials or OpenTelemetry headers. **[high]**
* [Desktop SSH and managed-device settings](p2-desktop-ssh-and-managed-device-settings.md) - Desktop-app keys for local-session blocking, SSH connections, SSH host allowlist and preview script control.
* [Desktop tool restriction settings](p2-desktop-tool-restriction-settings.md) - Managed keys that stop Claude's tools in the desktop app's Browser pane and iOS Simulator pane.
* [disableAllHooks and status-line gates](p2-disable-all-hooks-and-gates.md) - Turns off hooks, custom status line and file suggestion; reach depends on which file carries the key. **[high]**
* [Display, rendering and transcript settings](p2-display-and-rendering-settings.md) - Settings for theme, renderer, transcript view, time format, scrolling, motion and screen-reader output.
* [Dynamic workflow settings](p2-dynamic-workflow-settings.md) - Settings to turn dynamic workflows on or off, disable the ultracode keyword trigger and set a size guideline for agent count. **[high]**
* [enabledPlugins and extraKnownMarketplaces](p2-enabled-plugins-and-extra-marketplaces.md) - Per-plugin on/off switches and named marketplace registration, with source types, headersHelper and key aliases.
* [Footer badges and custom file suggestion](p2-footer-links-and-file-suggestion.md) - footerLinksRegexes turns IDs in output into footer link badges; fileSuggestion replaces the @ autocomplete with your own command.
* [Login restriction and gateway settings](p2-force-login-and-gateway-settings.md) - Settings that force a login method, organization or cloud gateway and declare internal gateway address blocks.
* [Commit and PR attribution settings](p2-git-attribution-settings.md) - Settings that control the attribution trailer on commits, the text on pull requests and the claude.ai session link.
* [hooks setting](p2-hooks-setting.md) - The settings key that registers hooks per event as matcher groups with command, prompt, agent, http or mcp_tool handlers. **[high]**
* [HTTP hook URL and env-var allowlists](p2-http-hook-allowlists.md) - Settings that restrict which URLs HTTP hooks may call and which environment variables they may interpolate into headers. **[high]**
* [Dialog timeouts and usage-limit auto-continue](p2-idle-timeouts-and-auto-continue.md) - Settings that let unanswered dialogs expire and let a session wait out a claude.ai usage limit and resume by itself. **[high]**
* [includeGitInstructions](p2-include-git-instructions.md) - Controls whether Claude gets built-in commit/PR instructions and a git status snapshot, and when the snapshot is dropped in headless and SDK runs. **[high]**
* [Managed source merging and policyHelper](p2-managed-source-and-policy-helper.md) - How managed sources combine (first-wins or merge), embedding-host parent settings, and the policyHelper that computes policy at startup. **[high]**
* [strictKnownMarketplaces and blockedMarketplaces](p2-marketplace-allowlist-policy.md) - Managed allowlist and blocklist of plugin marketplace sources, with source types, owner wildcards and exact-match rules.
* [MCP allowlist, denylist and managed server keys](p2-mcp-managed-policy-settings.md) - Settings that restrict which MCP servers load, provide managed servers and control claude.ai connectors alongside managed-mcp.json. **[high]**
* [Plugin admin and trust settings](p2-plugin-admin-trust-settings.md) - Managed keys for command-source plugins, contextual plugin suggestions and the plugin trust message.
* [pluginConfigs and mod ordering keys](p2-plugin-config-and-mod-order.md) - Stored plugin option answers plus the managed lists that run organization mods before or after users' mods.
* [Project .mcp.json approval settings](p2-project-mcpjson-approval-settings.md) - Settings that approve or reject MCP servers from a project's .mcp.json file without prompting. **[high]**
* [Prompt input, shell mode and voice settings](p2-prompt-input-and-shell-mode-settings.md) - Settings for the input box: editor mode, emoji, spellcheck, voice, suggestions, file picker, shell mode and plan-approval menu.
* [Notification and recap settings](p2-push-and-local-notification-settings.md) - Settings for mobile push notifications, local notification channel and the away summary recap.
* [Remote Control, deep link and cloud environment settings](p2-remote-control-and-cloud-env-settings.md) - Settings for Remote Control auto-connect and disabling, deep-link registration and the default cloud environment. **[high]**
* [Retention, feedback and telemetry-adjacent settings](p2-retention-and-feedback-settings.md) - Settings for transcript retention, desktop transcript age limit, Claude-drafted feedback, survey rate and WebFetch preflight. **[high]**
* [Sideload flags and fail-closed settings refresh](p2-sideload-and-remote-refresh-settings.md) - Managed keys that reject sideloading CLI flags and block startup until server-managed settings are freshly fetched. **[high]**
* [Skill and synced-plugin settings](p2-skill-visibility-and-sync-settings.md) - Settings that disable bundled skills, inline shell in skills, override skill visibility and stop claude.ai skill and plugin sync. **[high]**
* [Spinner tips, verbs and status line](p2-spinner-and-status-line-settings.md) - Settings for spinner tips, spinner verbs and the custom status line command.

* [Update channel and version pinning settings](p2-update-channel-and-version-pinning.md) - Settings that choose the auto-update channel and set minimum or maximum Claude Code versions.

* [Settings reference: related pages](p3-related-pages.md) - Pages the settings reference points to for permissions, env vars, tools, example files, managed settings and debugging.
